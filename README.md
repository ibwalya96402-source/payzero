# PAYZERO

PAYZERO is a marketplace platform designed to connect buyers and sellers in Zambia.

## Features
- Buyer and seller marketplace
- Online shops and product listings
- Payments and marketplace services
- Responsive web interface

## Getting Started

Install dependencies:

```bash
npm install
npm run dev

Open http://localhost:3000 in your browser.

## Built With
- Next.js
- React
- TypeScript
- Tailwind CSS
